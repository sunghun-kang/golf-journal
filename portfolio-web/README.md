# 내 자산 한눈에 보기 — 폰 전용 웹앱 (코드 전용)

PC 없이 폰/패드 브라우저만으로 쓰는 포트폴리오 대시보드입니다.

- **보유내역·금액은 이 기기(브라우저 localStorage)에만** 저장됩니다. 이 폴더/저장소에는 금액 데이터가 없습니다.
- 시세는 폰에서 직접 조회(네이버/야후, CORS 프록시 경유)하고, 실패 시 스냅샷/캐시로 폴백합니다.
- 홈 화면에 추가(PWA): 아이폰 Safari 공유 → "홈 화면에 추가" / 안드로이드 Chrome 메뉴 → "홈 화면에 추가".

## 처음 사용
1. 앱을 열면 "보유내역 가져오기" 창이 뜹니다.
2. `portfolio.json`(개인 파일)을 **파일 선택** 하거나 내용을 **붙여넣기** → 가져오기.
3. 데이터는 폰에만 저장됩니다. 이후엔 자동으로 불러옵니다.

## 버튼
- **↻ 시세 새로고침**: 현재가 다시 조회
- **📂 데이터**: 가져오기 / 내보내기(백업 다운로드) / 샘플
- **✎ 편집**: 계좌·종목·수량·평단 추가/수정/삭제(자동 로컬 저장)
